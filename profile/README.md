# 🏫 Hinthar International School — Dev Team

Welcome to the official GitHub organization for **Hinthar International School**'s engineering and design team. We are a student-led collective of IGCSE and International A-Level (IAL) developers building a modern, unified digital ecosystem for our school and community.

**Our Mission:** Streamline daily school operations and elevate student and community well-being through fast, intuitive, and reliable software.

---

## 🚀 Core Platforms

We are currently engineering and maintaining four primary platforms:

| Platform | Scope & Purpose | Status |
| :--- | :--- | :--- |
| **School Management System (SMS)** | The administrative backbone of Hinthar International—handling student records, attendance, scheduling, and daily operations. | `Active Development` |
| **E2E (Learning Application)** | An interactive academic platform built to deliver structured study resources, lesson tracking, and student progress analytics. | `Active Development` |
| **School Website** | The official public portal showcasing Hinthar International School’s programs, announcements, and admissions information. | `Active Development` |
| **B+ ("Be Positive")** | A daily wellness and routine companion (hydration, sleep, habits, streaks) integrated with a privacy-first community blood donation coordination network. | `Active Development` |

---

## 🛠️ Tech Stack

Our projects are built on a modern, type-safe web stack optimized for performance and low-bandwidth reliability:

- **Frontend:** Next.js (App Router), React, TypeScript, Tailwind CSS
- **Backend & Cloud:** Cloudflare Workers & D1, Firebase (Auth, Cloud Firestore, FCM), Vercel Route Handlers
- **Testing & Quality:** Vitest, Playwright E2E, ESLint
- **Design & QA:** Figma, Custom Design Systems

## 🤝 Internal Workflow & Guidelines

> **Access Notice:** Repositories under this organization are currently private and restricted to authorized Hinthar International School team members.

1. **Sync Before Building:** Always pull the latest changes from `main` or `dev` before cutting a new feature branch.
2. **Scoped Commit Messages:** Prefix commits with your project and layer so history stays scannable:
   - `[SMS-FE]` / `[SMS-BE]` — School Management System
   - `[E2E-FE]` / `[E2E-BE]` — E2E Learning Application
   - `[WEB-FE]` / `[WEB-BE]` — School Website
   - `[BPLUS]` — B+ ("Be Positive") Wellness & Blood Network
   - *Example:* `[BPLUS] Add 7-day post-donation hydration recovery banner`
3. **Pull Request Reviews:** All major PRs require approval from the **Lead Systems Architect (`@Noah`)** or **Project Manager / B+ Architect (`@Ko_Thorin`)** prior to merging.
4. **Design & QA Sign-Off:** Coordinate with the **UI/UX & QA** team before shipping significant layout or interface changes.
